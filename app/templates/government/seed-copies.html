Copias de prueba

Crea bases de datos SQLite ficticias para demostrar cómo un número trampa ayuda a identificar una copia filtrada.

SOLO DATOS SINTÉTICOS

Crear un lote

Se generará un archivo SQLite distinto por cada copia, con un número trampa único para la demostración.

Usa letras, números, guiones o guiones bajos. Cada identificador solo se puede crear una vez.

Cómo distribuirlas

El ZIP incluye un archivo por copia y una guía de uso. Entrega a cada participante únicamente la base que le corresponde.

La atribución queda privada. El ZIP no incluye la tabla que relaciona cada número trampa con su copia.
